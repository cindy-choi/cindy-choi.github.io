Experiment · Paged Attention

흩어진 메모리에서, 문맥은 순서대로

Paged Attention은 KV cache를 블록 단위로 다루어 흩어진 메모리에서 문맥을 순서대로 읽는 방법입니다. vLLM 논문을 바탕으로 한 교육용 모델입니다.

01 · Prefill / Decode

답이 길어질수록 무엇이 남을까?

prompt 네 토큰은 prefill로 한 번에, 답은 decode로 한 칸씩 KV cache에 쌓입니다. 모델 가중치는 그대로이고 캐시만 자랍니다.

끝날 길이를 모르는데, 자리는 얼마나 잡아둬야 할까요?

02 · Allocation

비어 있는데 들어가지 않는다

두 번째 질문 “그럼 고양이는 밤에 주로 뭘 해?”는 6토큰, 즉 KV 6칸이 필요합니다. 빈칸의 합은 충분해도 이어져 있지 않으면 들어가지 못합니다.

빈 블록을 골랐다면, 토큰의 순서는 어디에 기록될까요?

03 · Block Table

순서는 주소표에 남는다

물리 ID 순서로 짚으면 틀립니다. 주소표(L, offset)만이 토큰의 실제 위치를 찾습니다.

주소만 바뀌었다면, attention은 정말 같은 결과를 읽을 수 있을까요?

04 · Attention Read

흩어져 있어도 같은 attention이다

Q를 돌려도 연속·paged의 출력은 같습니다. softmax는 전체 문맥에 한 번만 적용됩니다.

문맥이 자라면, 빈 꼬리까지 계속 예약해야 할까요?

05 · Incremental Allocation

필요한 만큼 받고, 끝나면 돌려준다

블록은 실제 길이만큼 받고, 끝나면 풀로 돌아갑니다. 마지막 블록의 빈 꼬리(tail)는 남습니다.

같은 질문을 다시 풀 때도, 모든 KV를 새로 복사해야 할까요?

06 · Sharing + COW

함께 읽고, 달라질 때만 복사한다

A안과 B안이 같은 prompt 블록을 함께 읽습니다. 쓰는 순간에만 그 블록 하나를 복사합니다.

Epilogue

순서는 주소표에, KV는 빈 블록에. 같은 앞부분은 함께 읽고, 달라지는 블록만 따로 씁니다.

원 논문을 설명하는 교육용 모델입니다. 실제 vLLM 내부 구현이나 벤치마크가 아닙니다.
